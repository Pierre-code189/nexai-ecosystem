# NexAI CRM Core — Microservicio de Gestión de Clientes y Embudo de Ventas
**Puerto Predeterminado:** `3001`  
**Rol en el Ecosistema:** Motor Multi-Tenant con reconocimiento inteligente de rubro por IA, Tablero Kanban, gestión dinámica de contactos y analíticas.

## 🚀 Inicio Rápido
```bash
npm install
npm run dev # Se ejecuta en http://localhost:3001
```
