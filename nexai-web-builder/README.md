# NexAI Web Builder — Microservicio de Generación de Sitios Web
**Puerto Predeterminado:** `3000`  
**Rol en el Ecosistema:** Portal principal de adquisición y generador de páginas web mediante IA con editor visual en vivo.

## 🚀 Inicio Rápido
```bash
npm install
npm run dev # Se ejecuta en http://localhost:3000
```
