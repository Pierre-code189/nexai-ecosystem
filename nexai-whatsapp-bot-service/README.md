# NexAI WhatsApp Bot Service — Microservicio de Conectividad & Asistente IA
**Puerto Predeterminado:** `3002`  
**Rol en el Ecosistema:** Microservicio dedicado a la conexión directa por código QR (Baileys WebSocket), notas de voz Whisper, multiasesor y cobros Yape/Plin.

## 🚀 Inicio Rápido
```bash
npm install
npm run dev # Se ejecuta en http://localhost:3002
```
